完整學習路徑

課程大綱與週次進度

專為零基礎設計的階段式引導，結合體驗需求規劃、基礎網頁架構與 Gemini 實務協作，陪伴你親手完成專屬的品牌展示頁面。

Week 01 核心主題：需求整理與版面規劃

拆解品牌資訊與使用者體驗流程

學習站在訪客角度梳理資訊優先級，透過線框圖（Wireframe）整理出清楚的首頁動線，並建立對網頁骨架的基本認知。

重點學習項目
  • 目標客群需求梳理與品牌核心訊息定位
  • Hero 主視覺、特色區塊與 FAQ 內容層次規劃
  • 使用文字線框圖繪製清楚的頁面架構雛形
Week 02 核心主題：基礎網頁語法實作

看懂 HTML 架構與 CSS 樣式微調

不要求死記語法，而是學會看懂網頁骨架標籤與樣式屬性，能精準修改顏色、留白間距與文字層次。

重點學習項目
  • 語意化標籤（header、main、section、footer）基礎邏輯
  • CSS 溫暖色調設定、字級行高與邊界間距排版
  • Grid 與 Flexbox 基礎排版概念與手機版適配入門
Week 03 核心主題：資料整理與動態互動

認識 JSON 結構與 JavaScript 資料渲染

學會將網站文案與內容獨立成乾淨的 JSON 檔案，並透過簡單的 JavaScript 機制將資料自動顯示在網頁畫面上。

重點學習項目
  • 物件與陣列的基本概念：拆解 website-content.json
  • 原生 fetch 讀取本地資料的基本流程與除錯注意事項
  • 手風琴折疊常見問題（details / summary）互動實作
Week 04 核心主題：AI 協作與網頁發佈

Gemini 提問協作、問題排查與成果整合

掌握向 AI 提出精確提示詞的對話方法，借助 Gemini 協助修正跑版、擴充內頁內容，並整合出完整的品牌展示網站。

重點學習項目
  • 如何向 Gemini 具體描述版面調整與程式需求
  • 利用瀏覽器開發者工具找出樣式錯誤並請 AI 協查
  • 整合各分頁連結、測試聯絡信箱按鈕並確認最終呈現

準備好親自動手做出你的品牌網頁了嗎？

每週均搭配具體實作習作，不需任何程式底子，跟著步驟就能循序漸進看到自己的網頁成形。
