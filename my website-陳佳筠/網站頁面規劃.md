### 網站名稱建議

* 主名稱：AI 輔助品牌網站與使用者體驗設計實戰班
* 簡稱或副標：初學者的品牌網頁實作課

### 1.網站目的

介紹實戰班的核心價值與學習流程，消除初學者的程式恐懼，引導目標受眾了解如何運用 AI 工具完成專屬的品牌展示型靜態網頁，並促進課程諮詢與報名。

### 2.目標使用者

* 沒有深厚程式背景但希望自建網站的初學者
* 想打造個人展示頁面的創作者與接案工作者
* 需要為產品或服務建立基礎品牌門面的小型品牌主

### 3.後續產出程式碼時要遵守的限制

* 使用純靜態 HTML、CSS、JavaScript 與 JSON，不引入需要額外安裝的框架或後端環境。
* 樣式與腳本初期集中在各頁面的 style 與 script 標籤中，保持修改與除錯的單純度。
* 首頁需透過原生 JavaScript 的 fetch 機制正確讀取 data/website-content.json。
* 保持視覺色彩溫暖舒適且具陽光感，排版層次清楚俐落，避免生硬的 AI 感與過多專有名詞。
* 每次溝通僅產出單一頁面或指定區塊，確保程式碼能在 VS Code 中順暢測試與微調。
